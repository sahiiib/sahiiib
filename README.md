## Building at Netriun

### [Netriun Nexus](https://github.com/Netriun-com/netriun-nexus)

A multi-tenant control plane for multi-cloud operations, approvals, access management, and live infrastructure health. It brings AWS, Alibaba Cloud, Microsoft Azure, and Google Cloud operations into isolated account workspaces, with an embedded web UI and a versioned REST API.

**Built with:** Go · PostgreSQL · Valkey · Docker · Kubernetes/Helm

**Licensing:** Open-core, with the Community/Core licensed under AGPL-3.0-only.

Explore the project and its documentation in the [Netriun organization](https://github.com/Netriun-com).
